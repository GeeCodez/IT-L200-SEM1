### GOALS OF THE UML
* It provides a standard 
* It helps developers to understand complex systems.


## CONCEPTUAL MODELING
* **Class**: blueprint for objects.
* **Abstraction**: displaying the relevant characteristics of an object to users while hiding the irrelevant information.
* **Inheritance**: Deriving a new class from the existing ones.
* **Polymorphism**: Representing objects having multiple forms used for different purposes.
* **Encapsulation**: binding the data and the object together as a single unit, enabling tight coupling btn them.
